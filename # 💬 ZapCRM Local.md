# 💬 ZapCRM Local

Um mini CRM desktop moderno e automatizado para gerenciamento de conversas do WhatsApp, desenvolvido em **Python** utilizando **Flask**, **Pywebview**, **SQLite** e **Playwright**.

---

## ✨ Funcionalidades

- **Interface Desktop Moderna:** Janela nativa e independente (Dark Mode) sem precisar manter o navegador poluído aberto.
- **CRUD Completo:** Adicione, edite, atualize o status (*Aguardando*, *Urgente*, *Fechado*), adicione lembretes e exclua conversas diretamente pela interface.
- **Banco de Dados Local (SQLite):** Todos os dados do seu CRM ficam seguros e salvos localmente na sua máquina.
- **Automação com Playwright:** Integração real com o WhatsApp Web que abre o navegador com sessão persistente (você escaneia o QR Code apenas na primeira vez).

---

## 🛠️ Tecnologias Utilizadas

- **Python** (Backend, lógica e automação)
- **Flask** (API e rotas web locais)
- **Pywebview** (Transforma a aplicação web em um app desktop nativo)
- **Playwright** (Automação do navegador para o WhatsApp Web)
- **SQLite** (Banco de dados leve e embutido)
- **HTML5, CSS3 & JavaScript** (Interface do usuário responsiva e dinâmica)
